# Kounen – Semantic HTML5 Portfolio

## Task covered
- Multi-page personal portfolio
- Semantic HTML5 structure
- ARIA labels and roles where useful
- Keyboard/tab navigation
- Skip-to-content link
- Accessible contact form with labels and live status
- SEO-friendly title and meta description on every page
- Responsive CSS
- Reduced-motion support

## Pages
- index.html — Home
- about.html — About
- projects.html — Projects
- contact.html — Contact

## How to run
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Test every navigation link.
4. Press Tab repeatedly to test keyboard navigation.
5. Run Chrome DevTools → Lighthouse → Accessibility and SEO.

## Important
The contact form is a front-end demo. It validates the fields but does not send email until connected to a backend/form service.
